# 全站功能回归 QA

本轮检查覆盖词典、参考语法、记音对应、历史比较、语料与文献，以及中英界面、南北拼音、分享链接、下载和失败重试。以 `6d5b7348835532e6905b6876a8301c70bf8a0e21` 为基线，在合并全部修复后的同一份发布构建上复测。

发布收尾期间合并了 `e648006`、`5743042` 的“毕兹学堂”品牌与中英页面标题更新，保留所有 QA 修复，并补测合并后的标题、双语界面、手机布局、导航及正文延迟加载。词典数据的校验值仍与原基线相同。

已复现的问题均已修复，最终回归检查通过。本报告中的问题包含按需加载的边界问题和原有交互问题；没有将所有问题都归因于本次性能优化。

## 发现的问题与修复

| 问题 | 可复现的表现 | 修复与验证 |
| --- | --- | --- |
| 导出内容受后续搜索影响 | 点击导出“水”的 225 条结果，等待数据期间改查“茶”，下载变成 32 条茶相关记录。 | 在点击时保存结果集合；延迟数据返回后检查实际下载内容，仍为原先选择。 |
| 导出失败没有反馈，可重复提交 | 词条数据返回 404 时没有下载也没有提示；替换结果 DOM 后可再次触发导出。 | 增加忙碌状态、中英失败提示及重试；锁定替换后的按钮，验证仅产生一次下载。 |
| 导出加载过多数据、异常数据不能重试 | 小范围结果也读取整本词典；成功状态的空包或错误结构可能被缓存。 | 单条读取独立词条，多条只读相关批次；检查数据结构并清除无效缓存。全量下载仍保留完整原始字段、证据和注释。 |
| 英文加载失败后不能恢复中文页面 | 冷启动英文语法或分享链接，翻译请求失败，切回中文仍停在错误或加载画面。 | 保留当前页面的恢复任务，切换语言后继续原初始化；验证详情 ID、筛选、前进后退及其他 URL 参数。 |
| 部分数据就绪后词性筛选未初始化 | 全站搜索中，词汇索引成功而翻译失败，切回中文或重试后词性下拉仅剩默认项。 | 同步就绪与异步完成两条路径都执行词性初始化。 |
| 过期翻译请求影响新页面 | 等待英文语法时切到历史比较，旧语法请求失败后将新页面退回中文。 | 按当前页面重新核对所需模块，旧页面的无关失败不再改变新页面语言。 |
| 语法切换语言后结果不更新 | 中文检索 `negation` 为 0 条，切英文仍为 0 条，实际应为 8 条。 | 翻译就绪后刷新已提交查询，保留搜索草稿、选区、滚动位置和历史状态。 |
| 带南北范围的文献链接冷启动报错 | 直接打开限定北部或南部资料的链接，未先访问语法时依赖缺失。 | 文献页独立提供范围标签，验证中英界面和南北范围四种冷启动。 |
| 加载中连续切换拼音丢失搜索草稿 | 英文仍在加载时调整南北拼音，原草稿或选区被加载画面覆盖。 | 将草稿绑定到当前恢复任务；验证连续调整、离开页面和清除筛选，不将旧草稿带入新页面。 |
| 语料时间标记显示与备份不一致 | 超过录音时长的标记在界面上被清除，却仍留在本机存储及导出备份。 | 录音时长已知时统一清理显示、内存、存储和备份；补测稍后收到音频元数据的情况。 |
| 时间备份接受非语料 ID，保存失败提示失真 | 特殊属性名可能通过 ID 检查；本机写入失败后又出现“已保存”提示。 | 只接受真实语料自身 ID，校验备份结构和文本签名；保存失败时保留可导出的会话标记，并显示真实失败结果。 |
| 已加载语料的时间备份仍依赖全库请求 | 当前文本已可读，导入其时间备份却因其他语料请求失败而被阻止。 | 先检查备份，只读取缺失的目标语料；分别验证离线导入、部分成功、全失败与同一文件重试。 |
| 空结果与详情对话框提示不足 | 语法无匹配时没有反馈；详情对话框没有可访问名称。 | 补充既有的双语空结果提示，并以详情标题命名对话框。 |
| 手机筛选框文字不可见 | 320 px 英文界面的四个筛选框挤在一行，每个约 61 px，关闭时几乎只显示箭头。 | 手机端改为两列换行，为当前选项保留文字空间，并加入相应布局断言。 |

## 验证边界

- 浏览器测试使用 Chromium；手机检查是视口模拟，没有在真实 iPhone、Safari 或 Firefox 上实测。
- 当前仓库没有 26 段普通录音的本地媒体镜像；这是基线中已有的资源缺失。检查确认缺失时保留原始录音链接且正文可读。合成 WAV 验证了播放器逻辑，原始外部录音的可用性和内容没有逐段试听核验。
- 本轮验证了加载顺序和超时重试行为，没有测量中国内地实际运营商网络的访问速度。
