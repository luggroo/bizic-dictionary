## 修复结果

| 用户可见的问题 | 根因与处理 |
| --- | --- |
| 历史比较无法打开，部分全站搜索报错，语保例句与龙山文本详情无法打开 | 删除收藏、笔记功能后仍有 6 处 `bookmark()` / `noteArea()` 调用；已移除遗留调用及空表列。 |
| 手机返回离开网站，章节和页面历史不正确 | 原导航只用 `replaceState`，未处理 `popstate` / `hashchange`；现统一管理页面、章节与浏览历史。 |
| 返回或刷新后丢失搜索、筛选、分页或语料来源集 | 将已有检索状态写入页面 URL；历史记录保留页面位置和折叠区展开状态。 |
| 打开详情后按返回不能先关闭 | 普通词条、语料、文献、比较详情和记音单元格证据均接入一层弹窗历史；前进可重开，弹窗内切换条目不叠加历史。 |

| 语法脚注点不到折叠的出处，刷新后丢失章节 | 脚注定位先展开上层折叠区，并保留章节 URL；旧脚注链接可以推回对应章节。 |
| 语法检索文献后 URL 仍停在语法页 | 跨页面检索统一经过导航，保留检索词和南北资料范围。 |

| 输入无效文献页码可能使阅读器报错 | 页码入口要求有效整数，阅读器补充有限数检查和范围约束。 |

## 可复跑的回归脚本

需先安装 Playwright 及对应浏览器。测试服务器默认挂载在 `/bizic-dictionary/`，覆盖 GitHub Pages 子目录路径。

```sh
node scripts/test-search.cjs
node scripts/test-yubao-english.cjs
node scripts/test-ui-language.cjs
node scripts/test-mobile-navigation.cjs
BROWSER=webkit node scripts/test-mobile-navigation.cjs
```

`CHROMIUM_EXECUTABLE` 可指定 Chromium 可执行文件；`PLAYWRIGHT_BROWSERS_PATH` 可指定浏览器目录。`BASE_URL=https://luggroo.github.io/bizic-dictionary/` 可对线上地址复跑。`QA_FOCUS=notation` 可单独复跑记音弹窗和转换状态场景。

`test-search.cjs` 增加了英文校注、嵌套括号以及普通义项限定的回归检查；`test-ui-language.cjs` 已去掉被删除的收藏功能假设，并断言收藏、笔记入口不再出现。
