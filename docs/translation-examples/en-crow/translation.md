说明：

- pitcher以词库“罐”概括；found用“碰到／偶遇”；beak以“嘴”概括。保留“口渴”对乌鸦的修饰；“罐里少量水”为另一个完整补充断言。
- 精确缺口仅插入“够不到”“试推倒”，保留汉字，IPA为null；未为插入项猜音。尝试小句用裸谓语，不把未成功推倒标为已完成。
- 水太低／嘴够不到的原因结果关系采用相邻小句；转折用dángsí。独立断言分别成组，同主语省略不据此合并。
- “一个一个”采用可复用的lá bú lá bú mǒ数量重叠方式构式；bú的量词类别明确含石头。
- PFV liē只标碰到、投石、水上涨等事件；一般条件能力dēxǐ和高程度xǐtái均保持整体。
- 记音保留所选词条配对：hǔ的词库IPA为fu²¹；xié为ɕiɛ²⁴。高程度xǐtái保留鲁曼例的ɕi²¹tʰai³⁵；其他词主要采用Brassett龙山来源基记，连读未核。

标签：PFV = perfective；LNK = linker；CONN = connective；ADVZ = adverbializer；ALL = allative。
