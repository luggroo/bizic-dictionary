# 语料、语法与历史比较的加载优化

这三页继续独立于词典索引。语料目录先读取摘要，选中文本才读取正文；中文阅读暂不下载英文长篇译文，选择英语时读取并复用。语法搜索复用章节排版与搜索文本，历史比较的相关词条在点按后读取。

## 加载方式

- 语料目录从 196.9 KB 的完整包改为 43.3 KB 摘要。按文本 ID 分开发布正文、词语对照和原始信息，打开哪段就读取哪段。全文搜索另读标准化文本；中文、英语标题、IPA、地点与人物检索范围保留。时间标记导入在需要核验全库时读取完整语料。
- 语法和语料的英文长篇译文在选择英语时载入，具有超时与重试。切回中文、再次选择英语时复用资料；英语直达链接仍在对应内容准备好后显示。
- 语法章节 HTML 和搜索文本按语言、拼音显示与译表状态缓存，并限制缓存数量。手机提交搜索后收起章节目录，使结果出现在目录下方。
- 历史比较不再引入旧版语法数据，也不自动下载约 672 KB 的词典摘要。读者点“查看相关词条”后再读取词典并显示相同释义的记录；原有比较形式、出处及检索保持一致。
- 原有完整语料包保留，旧页面仍能访问。摘要和搜索内容参与缓存版本计算，功能脚本继续使用内容指纹。

## 验证

逐一比对 487 段语料的完整独立文件、目录字段和标准化搜索文本，包含英文标题别名；原有拼音、注释和音标不因拆分而改变。

浏览器确认：目录不会提前读取正文，打开一段仅补齐该段；全文搜索不补读所有正文；中文阅读不预载英文长篇译文；选择英语能重试临时失败并复用载入结果；语法缓存检索与渲染后的完整文本一致，覆盖南北及各拼音模式；历史比较详情不请求词典，点按相关词条后才请求。独立来源详情、旧式解压、分享链接、快速切页和异常恢复也通过检查。
