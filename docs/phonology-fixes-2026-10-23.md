# 语音章节与拼音切换修复

本次在 `8c0e444` 基础上修改，保留原始词典、来源 IPA、调查点和声调记录。

## 对应与显示

- 北部语法与仙仁转换器中的 `/ɛ/` 在拼音声母 j、q、x、y 后统一使用 ie 类拼写：`jie、qie、xie、ye`。包含 j 的浊音变体，保留原始记音与调值；例如 `/tɕɛ⁵⁴/` 显示为 `jiev / jiè`。其他声母后的 `/ɛ/`、原有 `/ai/` 和其他来源的规则保持原样。
- 普通正文中的 `ng ng [ŋ]`、`hx hx [ɣ]`、`r r [z]` 保留一组拼音与 IPA。去重不移除真实重复形式，也不把英语介词 `in` 当作鼻化元音的拼写删除。
- `e／ə` 等明确的音值对照保留为纯 IPA，不在同一对照中插入额外拼音。
- 显示模式切换保留未提交的搜索草稿，不改变已经提交的检索、范围、结果或 URL。

## 阅读结构

北部语音页面按“音节结构 → 声母 → 韵母 → 声调 → 方言差异 → 连读变化”组织。较长的声母、韵母与调查点对照表可展开阅读；原先散落在不同折叠块内外的声调材料归到相应主题。重复的他砂四调展示合并，保留词例、汉义和表 2.6 的来源。

南部先介绍音节结构，再列声母、韵母、声调及前缀变调；使用自己的音系和调值。中英文阅读提示和标题同步更新。正文来源是 `reference-grammar.md`，通过 `scripts/build-reference-grammar.mjs` 重新生成网站数据。
