# 词性标签的归并与层级

词性筛选采用四组：实词、虚词、词缀与构词成分、其他；具体词性在来源有明确标注时再显示下位类。

- 缩写、拼写变体和中英异名统一到稳定 ID，例如 `n.`、`noun` 和 `名词` 均对应 `noun`。
- 兼类词可以属于多个类别；筛选“动词”会包含“及物动词”等子类。
- 词条的 `pos`、`positions` 和 `attestations[].pos` 仍保存原记录；标准化只影响网站的筛选、展示及导出新增的 `canonicalPos`。
- 对未标注或无法可靠识别的词性，显示“词性未定”，不根据释义推断。
- 维护：`site/word-classes.js` 存储类别与异名；运行 `node scripts/test-word-classes.cjs` 会审计尚未映射的来源标记。
