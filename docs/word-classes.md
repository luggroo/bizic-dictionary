# 词性标签的归并与层级

词性筛选采用四组：实词、虚词、词缀与构词成分、其他。来源标签与本站分析分开保存。

- 缩写、拼写变体和中英异名统一到稳定 ID，例如 `n.`、`noun` 和 `名词` 均对应 `noun`。
- 兼类词可以属于多个类别；筛选“动词”包含“及物动词”“情态动词”等子类。
- `pos`、`positions` 和 `attestations[].pos` 保留原记录。本站审核分类放在 `site/lexical-reviews.js`，不回写这些来源字段。
- 释义与组成较明确的名词、动词、量词、代词、数词、情态动词可增加本站标签。不能确定属于动词还是形容词的性质词归 `property`，列表缩写为 `qual.`，完整标签为“性质词（动／形待定）”；它是检索用的暂定类，不是已确立的句法词类。
- 宾语＋谓语表达归 `phrase.verb`（`v. phr.`），主谓表达归 `phrase.subject_predicate`（`phr.`），另存 OV/SV 结构。结构未明的条目不强行归类；“一点”归不定量表达，“几个”归疑问词与疑问表达。
- 未标注、尚无可靠分类的条目仍可用“词性未定”筛选，词卡不增加空标签。
- 原文献直接支持的类别使用普通样式；本站推测类别用灰色细虚线。悬停、键盘聚焦或点按详情标签显示双语依据、原标签及不确定性说明；列表标签有双语 title，点开词条可查看同一说明。编者注明示 AI 辅助判断可能有误。
- 导出保留原字段，并新增 `canonicalPos`、`posProvenance`、`sitePosAnalysis`，区分规范化类别、标签来源与本站分析。

已核对原始词库中的 46 种词性标签写法：

- `be v.`/`be` 标注状态谓词，归“状态动词”；`vc.` 归“系动词”；`va.` 归“助动词”。
- `advm.`、`advt.`、`advl.`、`advd.` 合并展示为“副词”，保留文献中的细类标签。
- `nbp`、`nveg`、`Nanim`、`nrel` 归“名词”；`onom.` 归“拟声拟态词”；`expr.` 归“短语与表达”。
- `dem` 和 `intg` 按“指示代词”和“疑问代词”检索。部分形式也可充当状语，需结合句法语境理解。
- `n+vt.` 一类组成标记不能作为“名词”和“及物动词”两个直接来源词性背书；审核后的短语分类保持本站分析身份。

维护入口为 `site/word-classes.js`、`site/lexical-reviews.js` 和 `site/word-class-ui.js`。检查包括词性归并、真实词库审核、来源保留、显示分词及预生成搜索数据的一致性。详见 `pos-audit-2026-10-23.md`。
