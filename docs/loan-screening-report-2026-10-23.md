# 借词全量筛查与修复记录（2026-10-23）

本轮对 16,577 个合并词条做了全量计算筛查，逐项核对后补充 28 条“可能借自汉语”的注释：10 条整词、18 条部分音节。原始 IPA、调值、来源记音和登记释义保持原样。新增注释没有推定借入年代。

“尸体 setu”锁定排除，覆盖五条相关词形及其合并别名；不同词形的南部 sītī /si⁵⁵tʰi⁵⁵/ 不属于这次 setu 排除范围。

## 筛查方法与覆盖范围

按来源 IPA 切分音节，以声母、韵母、声调、三者组合和相邻音节组合为特征，北部、南部分别拟合 8 次抽样的逻辑回归模型。汉义、英语释义、来源 ID 和现有借词标签不进入预测特征；它们用于后续检索与核对。

训练目标是区分“已审整词借词”和“未标注背景”。未标注项中仍有借词，明确记录为本土词的种子只有 7 条，因此本轮不能给出可靠的借词／本土词二分准确率。分数只安排核查顺序，不代表借入概率。

124 条不能完整切分的记录中，109 条未标借词，15 条已有注释。主要问题是未记声调、末音节缺调或特殊记音。它们保留在覆盖清单中，不补造声调。检索中的汉义字面重合只是筛选条件，不能替代词义核对。

五折验证按相同汉义或相同去调音段归组，避免同形异调和跨来源重复词直接分散到训练、验证两侧。北部已审 1,982 个整词词形、未标注 11,585 个词形，标签区分 AUC 为 0.8604；南部相应为 815、2,977、0.8631。这是对已有标签的区分能力，不是词源判定准确率。尚未登记的同源关系和不同来源的记音习惯仍可能造成偏差。

## 箭绳的修复

阳朝“箭绳” gōngjiānhxělǎ /kɔŋ⁵⁵tɕaŋ⁵⁵ɣə³³la³³/ 的整词排序分数为 0.403；分段扫描中，第 2 音节的分数达到 0.940。这个例子说明，只按整词排序容易遗漏混合构词。音节分数本身不能确定借入边界。

同点“弓”两条记录均为 /kɔŋ⁵⁵/；同点“绳子”是 /ɣə³³la³³/。据这些记录和“箭”的复合形式比较，本条仅在第 1—2 音节补注可能借入的“弓箭”，显示“半借”，仍能通过“隐藏整词借词”过滤。后半段与同点独立“绳子”记录一致。其他调查点的“箭绳”保持单独审核。阳朝“箭”中的同一前缀也只补注第 1—2 音节，完整汉语原词表达仍待核。

## 排除记录

[筛查约束表](loan-screening-constraints.json) 集中保存 92 条记录，区分整条排除、暂缓、否定特定原词、否定特定音形、限定部分音节。执行时先解析合并别名，再生成候选。既有的哥哥、语法后缀、拟音词及被撤回的词源推测继续受约束。

setu 相关五条为 `stedt-rn-353352`、`yubao-60756-v-2277`、`yubao-60757-v-2277`、`yubao-60823-v-2277`、`w1449`。回归检查要求这些词条保持无借词标记，并保留另一词形南部 sītī 的既有标注。排除某个汉语原词不会自动排除该词条的其他词源分析；“猪肝”也继续只标“肝”所在的第 2 音节。

## 验证与复现

数据和页面检查均通过：

- 新增 28 条注释的精确音形、音节范围、中英文、整词／部分借词过滤及原始来源记录。
- 390 与 1440 像素宽度下的中英文实页，共 112 组新增注释检查；另核对 24 组 setu 与“绳子”无标记页面。北部两种拼音、南部两种拼音均核对来源记录保持一致。
- 132,666 项预编译数据检查，覆盖全部 16,577 条词的 IPA、拼音、借词标记与语义分类；原生 gzip 与备用解压加载通过。
- 四组筛查程序回归：送气／鼻化／调值区分、setu 合并别名排除、精确音形排除、验证分组。
- 面向读者的文案检查通过。

修复后的借词标记分布为：整词 2,716、部分 232、含借词异读 22、未标 13,607。没有根据模型分数批量改写源数据。检查时 GitHub main 及现有 PR 引用相对本轮起点未变；后续新提交仍需按新版本重新运行 QA。

[重点队列 TSV](loan-screening-shortlist-2026-10-23.tsv) 可用表格软件打开。它同时列出已补注项与尚未核定的候选，不是一份全部通过审核的借词清单。全量词形排序、覆盖表、输入快照和可直接打开的 HTML 随完整报告包提供。
